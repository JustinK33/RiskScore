Survivorship bias and the embargo

Filtering to closed loans keeps every loan that has already defaulted and discards the ones still paying, so the measured default rate rises with every vintage - a book that looks like it is deteriorating when it is only younger. Requiring issue_d + term <= snapshot before the split fixes it, and costs the recent vintages entirely.

Embargo

Drift

Population stability index between the training partition and the test partition. The split is chronological, so this measures how much the book moved over the year between them - and a model whose score distribution has shifted is answering a different question than the one it was measured on. Under 0.10 is stable, 0.10 to 0.25 is worth watching, above 0.25 calls for a retrain.

Feature stability

Worst first. Watch the missing-rate columns as well as the index: a feature can hold a PSI of 0.01 while its missing rate moves from 0.1% to 4%, which is a pipeline change rather than population drift.
